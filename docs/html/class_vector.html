Detailed Description

template<typename T>
class Vector< T >

Sabloninis dinaminio masyvo konteineris.

Vector klase saugo elementus vientisoje dinamiskai paskirtoje atmintyje. Kai konteineryje nebelieka vietos naujam elementui, talpa yra padidinama. Klase realizuoja didele dali std::vector funkcionalumo.
